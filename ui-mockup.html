1 Lock screen

The gate, every time you re-open

Auto-locks after your chosen delay. Biometric first, device PIN fallback — no custom passcode. This is what a snooping bystander hits.

Decided

  • ✓
    Auto-prompt biometrics on open. One less tap daily; cancel drops to tap-to-retry.
  • ✓
    Full black behind the lock. Gives a bystander no hint content exists — over a blurred grid.
  • ✓
    Default auto-lock: 15s. Survives quick app-switches; still tight. Immediate / 15s / 60s stay configurable.

    Video tiles: play marker + duration.
  • ✓
    No bottom nav in v1. Albums are v2, so a tab bar would be dead weight. Single screen; Settings in ⋮.

3 Share sheet PRIMARY

The daily move: “Share → Vault”

Long-press an image anywhere → Share → Vault. Optionally tap a tag, hit Save, it’s gone. No biometric prompt — public-key wrapping means saving never needs auth. The flow to get perfect.

Decided

  • ✓
    Quiet “From WhatsApp” line. Icon + cached label; the raw android-app:// id stays out. Chevron to correct it.
  • ✓
    Keep the confirm sheet — no auto-save. The tap-to-save moment is the only tagging that actually happens. Save is default focus, so it’s still ~one tap.
  • ✓
    Six quick-tag chips by use, plus “+ new”.
  • ✓
    Button reads “Save to Vault.” Invoked from another app, where bare “Save” is ambiguous.

4 Full-screen viewer

One item, decrypted only in memory

Tap a tile to open. Swipe between items; pinch to zoom. Never written to a temp file, and screenshots are blocked here too.

Decided

  • ✓
    Metadata hidden until swipe-up. Photo gets the full screen; a slim peek reveals source / date / tags.
  • ✓
    Show the domain only, never the full URL. Implements the DB-leak mitigation right where a shoulder-surfer would read it.
  • ✓
    Item actions: retag · export-one · delete. No share-out (it’d decrypt to another app); add-to-album is v2.

5 Import

Pulling media in — and out of your gallery

Your own picker (Android’s can’t delete originals). The second tab is the folder import from your note: point it at a directory, it encrypts copies in, no plaintext left for the stock gallery to scan.

Decided

  • ✓
    Two tabs: “Photos & videos” and “From a folder.” Same pipeline; each entry point keeps its own affordances.
  • ✓
    “Delete originals” defaults OFF. Deletion is irreversible and the vault has no recovery path — earn trust first. Revisit once export is proven.
  • ✓
    Return to the grid after import, scrolled to the new items.
